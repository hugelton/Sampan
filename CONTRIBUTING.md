# Contributing

Thank you for helping. A few things keep this small project manageable:

- **Bugs:** one issue per bug, with what you did, what you expected and what
  happened, the board, and the status line `sampan-recv` prints (it shows
  the firmware version and what the board found).
- **Ideas and requests:** Discussions, not Issues.
- **Pull requests:** small and focused. Run `make test` first; for firmware
  changes say which board you tried them on. New source files start with
  the SPDX line and copyright notice used in the rest of the code.
- Contributions are under GPL-3.0-only and credited in the README.
